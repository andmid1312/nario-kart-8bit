# Nario Kart 8Bit + Retro Spel-Byggare

Självständiga HTML5-spel (ingen server behövs).

## Nario Kart 8Bit

8-bit inspirerad kart-racer med Mode-7-känsla, karaktärer (Benny4real m.fl.), två banor (Prismabanan & Växjöringen), items, AI, minimap, touch-kontroller och nu även:

- Retro-ljud (Web Audio, ingen extern fil)
- Personbästa-tider sparade i localStorage per bana

## Spela online (githack, text/html)

- **Nario Kart:** https://raw.githack.com/andmid1312/nario-kart-8bit/main/index.html
- **Retro Spel-Byggare:** https://raw.githack.com/andmid1312/nario-kart-8bit/main/retro-byggare.html

CDN-variant: https://rawcdn.githack.com/andmid1312/nario-kart-8bit/main/retro-byggare.html

## Lokalt

Öppna `index.html` (kart) eller `retro-byggare.html` (byggare) direkt i webbläsaren (file://).

## Utveckling

Byggd som single-file för enkelhet. Ytterligare förbättringar (fler banor, fler items, bättre AI, local multiplayer) är naturliga nästa steg.
