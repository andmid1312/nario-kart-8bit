# Nario Kart 8Bit + Retro Spel-Byggare

Självständiga HTML5-spel (ingen server behövs). Öppna filerna direkt i webbläsaren.

## Nario Kart 8Bit

8-bit-inspirerad kart-racer med Mode-7-känsla, fem förare (Benny4real, Ferdi, Annie, Balto och Bobban), två banor (Prismabanan och Växjöringen), föremål, AI, minimap och touch-kontroller.

## Spela online

- **Nario Kart:** https://raw.githack.com/andmid1312/nario-kart-8bit/main/index.html
- **Retro Spel-Byggare:** https://raw.githack.com/andmid1312/nario-kart-8bit/main/retro-byggare.html

## Lokalt

Öppna `index.html` (kart) eller `retro-byggare.html` (byggare) direkt i webbläsaren (`file://`).

## Utveckling

Byggd som en enda HTML-fil för enkelhet. Fler banor, fler föremål, bättre AI och lokalt flerspelarläge är naturliga nästa steg.
